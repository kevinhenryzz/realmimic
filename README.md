# realmimic: SuperMimic on one RTX 4090

The goal: reproduce SuperMimic ([Liao et al., 2026](https://arxiv.org/abs/2610.28480)), a whole-body motion tracker
for the Unitree G1 trained through a learned differentiable world model, on a single RTX 4090 (24 GB), measure it on
the paper's own benchmark, and run it through NVIDIA's SONIC deploy runtime.

Independent and unofficial. Documentation follows with the code.
